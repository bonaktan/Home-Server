# Package reporting adoption

These repository inputs are prepared for the Atom; they are **not installed** and the package phase remains disabled. Do not use the old bootstrap scripts or run upgrades as a substitute for the gate.

The intended installed files are `/etc/apt/listchanges.conf.d/home-server.conf`, `/usr/local/lib/home-server/listchanges-output.sh`, `/etc/logrotate.d/home-server` and `/etc/update-motd.d/95-apt-changes`, from the corresponding `infra/host` and `scripts/host` files. The package-owned `/etc/apt/apt.conf.d/20listchanges` supplies the version-2 APT hook and must remain in place. The observed competing `/etc/apt/apt.conf.d/05listchanges-redirect` is to be retired only after inventory, backup and validation. Preserve the existing seen database and previous changelog history; the new log does not automatically import the old `/var/log/apt-listchanges-since-login.log`. Do not alter the already-correct PAM dynamic MOTD configuration.

The log frontend appends NEWS and changelog text to `/var/log/apt/listchanges.log`; the filter passes the same text to the log and, when available, the controlling terminal. The MOTD reads a bounded tail without truncating it. Log rotation covers that changelog file; audit and operation logs must receive their own reviewed rotation when their capture paths exist. Rotation count is not proof of 30 searchable audit days.

Before installation, verify the exact existing files and overrides, permissions, logrotate integration and available space, preserve prior files/history, and prepare rollback. In a disposable Debian 13 fixture, exercise the package-owned hook during interactive and noninteractive package upgrades, rotation and login, failures and unavailable/full sinks. Inspect all newly retained representations for harmless sensitive markers and verify outcome attribution; the local tests exercise the filter and a synthetic version-2 hook but do not establish those wider gates. Only after review and successful checks should the maintained host phase adopt the configuration and retire the exact conflicting hook. Validate the first real run and restore the recorded files if it fails.
